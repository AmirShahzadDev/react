# React learning checklist

## 1. Components and rendering

- [ ] Local setup with Vite, JSX syntax, fragments, and expressions
- [ ] Function components, props, `children`, and composition
- [ ] Conditional rendering, list rendering, and stable keys
- [ ] Rendering, committing changes to the DOM, and component purity
- [ ] Event handlers, event propagation, and passing callbacks as props

## 2. State and forms

- [ ] `useState`, state snapshots, batched updates, and functional updaters
- [ ] Immutable array and object updates
- [ ] State ownership, lifting state, and one-way data flow
- [ ] Derived values, state structure, and avoiding duplicated state
- [ ] Preserving and resetting state with component position and keys
- [ ] Controlled and uncontrolled inputs, submission, and validation
- [ ] `useReducer` and Context for shared state
- [ ] Local state, shared state, URL state, and data from a server

## 3. Effects, hooks, and data

- [ ] Rules of Hooks and writing custom hooks
- [ ] `useEffect`, dependency arrays, cleanup, and Strict Mode
- [ ] Choosing between render logic, event handlers, and effects
- [ ] `useRef`, DOM access, and keeping mutable values between renders
- [ ] Data fetching, loading, empty and error states, race conditions, and cancellation
- [ ] Client-side routing, dynamic parameters, and search parameters
- [ ] Server data libraries, cache keys, invalidation, and optimistic updates

## 4. Production and advanced React

- [ ] Semantic markup, accessible forms, keyboard navigation, and focus management
- [ ] React DevTools, component inspection, and the Profiler
- [ ] Testing user interactions with React Testing Library and a test runner
- [ ] `lazy`, `Suspense`, code splitting, and error boundaries
- [ ] Measuring re-renders and using `memo`, `useMemo`, and `useCallback` selectively
- [ ] `useTransition`, `useDeferredValue`, and responsive updates
- [ ] React Actions, `useActionState`, `useFormStatus`, and `useOptimistic`
- [ ] Portals, dialogs, and reusable component APIs
- [ ] React Compiler basics and reading older class components
