# JavaScript learning checklist

## 1. Language fundamentals

- [ ] `let`, `const`, `var`, block scope, hoisting, and the temporal dead zone
- [ ] Primitive types, objects, `typeof`, `null`, `undefined`, and `NaN`
- [ ] Type conversion, coercion, truthiness, `===`, and `Object.is()`
- [ ] Operators, optional chaining, and nullish coalescing
- [ ] Conditionals, loops, `for...of`, and control flow
- [ ] Strings, template literals, numbers, dates, and `Intl`

## 2. Functions and data

- [ ] Function declarations, expressions, arrow functions, and default parameters
- [ ] Lexical scope, closures, callbacks, higher-order functions, and pure functions
- [ ] Arrays and collection methods such as `map`, `filter`, `find`, `some`, `every`, and `reduce`
- [ ] Sorting with comparators, mutating methods, and copying methods
- [ ] Objects, property access, destructuring, rest and spread, and property shorthand
- [ ] References, mutation, immutable updates, and shallow versus deep copying
- [ ] `Map`, `Set`, and when to use an array or an object
- [ ] JSON parsing, serialization, and error handling

## 3. Browser APIs and asynchronous JavaScript

- [ ] DOM queries, element creation, `textContent`, and safe rendering of untrusted data
- [ ] Events, bubbling, capture, delegation, and default behavior
- [ ] Forms, `FormData`, native validation, and keyboard interaction
- [ ] URLs, `URLSearchParams`, History API, `localStorage`, and `sessionStorage`
- [ ] Promises, chaining, `async`/`await`, `try`/`catch`/`finally`, and custom errors
- [ ] Call stack, event loop, tasks, microtasks, and timers
- [ ] Sequential and concurrent work with `Promise.all()` and `Promise.allSettled()`
- [ ] HTTP and `fetch()`, response status, parsing, cancellation with `AbortController`, and stale responses
- [ ] Browser security fundamentals, including same-origin policy, CORS, and XSS

## 4. Deeper language and production skills

- [ ] `this` binding, `call`, `apply`, `bind`, and arrow-function behavior
- [ ] Prototypes, classes, inheritance, and composition
- [ ] ES modules, named and default exports, dynamic imports, and CommonJS basics
- [ ] Iterables, iterators, generators, symbols, and regular expressions
- [ ] Node.js versus browser APIs, npm scripts, dependencies, and lockfiles
- [ ] DevTools, breakpoints, stack traces, network inspection, and source maps
- [ ] Unit testing, boundary cases, mocking network requests, linting, and formatting
- [ ] Debouncing, throttling, memory leaks, and browser performance profiling
- [ ] Advanced topics such as `WeakMap`, Web Workers, and streams
