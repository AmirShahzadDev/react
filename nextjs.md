# Next.js learning checklist

## 1. TypeScript and App Router fundamentals

- [ ] TypeScript types, unions, narrowing, generics, and typed React props
- [ ] TypeScript types versus runtime validation of API responses
- [ ] Project setup, development and production scripts, and the `app` directory
- [ ] File-based routing, pages, layouts, nested routes, and route groups
- [ ] Dynamic and catch-all segments, `params`, and `searchParams`
- [ ] Navigation with `Link`, prefetching, redirects, and router hooks
- [ ] URL-based search, filtering, sorting, and pagination

## 2. Server and client rendering

- [ ] Server Components, Client Components, and the `'use client'` boundary
- [ ] Composing server and client UI and passing serializable props
- [ ] Server-only modules, environment variables, and `NEXT_PUBLIC_` variables
- [ ] Static and dynamic rendering, prerendering, hydration, and streaming
- [ ] `loading.tsx`, `error.tsx`, `not-found.tsx`, and `Suspense`
- [ ] Fetching on the server, parallel requests, and avoiding request waterfalls
- [ ] Caching, Cache Components, cache lifetimes, and time-based or on-demand revalidation

## 3. Data, security, and Laravel integration

- [ ] Server Functions and Server Actions, form submissions, and mutation feedback
- [ ] Server-side validation, optimistic updates, and refreshing data after a mutation
- [ ] Route Handlers, HTTP methods, and when the frontend needs an API endpoint
- [ ] Calling a Laravel JSON API from Next.js and handling `401`, `403`, `404`, and `422` responses
- [ ] Authentication, cookies, sessions, and token handling
- [ ] Authorization for pages, Server Actions, and Route Handlers
- [ ] CORS for browser requests, CSRF protection, and safe handling of secrets
- [ ] Proxy and request-time redirects or rewrites

## 4. Production and advanced Next.js

- [ ] Metadata, Open Graph, sitemaps, and `robots.txt`
- [ ] Image and font optimization, accessibility, and Core Web Vitals
- [ ] Production builds, deployment environments, and Node.js hosting
- [ ] End-to-end tests, logging, error monitoring, and performance profiling
- [ ] Bundle analysis and keeping client-side JavaScript small
- [ ] Parallel and intercepting routes
- [ ] Pages Router basics for maintaining or migrating older apps
